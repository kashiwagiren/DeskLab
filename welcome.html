ℹ️ About

DeskLab is a comprehensive computer lab management system designed for educational institutions. Students can login to use computers, view schedules, and track their sessions. Administrators can manage requests, monitor usage, and maintain class schedules.

🚀 Getting Started

  1. Click "Verify Setup" to check your installation
  2. Go to Admin Dashboard to add classes
  3. Register students and enroll them
  4. Test the Student Interface
